# Bibliography

These 53 entries reproduce the numbered reference list of the source report *How AI Writing Detection Works* (`AI Detection.md`, research snapshot 24 October 2026). The companion guide (`natural_academic_writing_guide.md`) keeps the same numbering, so a bracketed number such as [18] means the same work in every file of this skill.

The source report consulted these web resources on 24 October 2026. Product pages change. A date attached to research identifies the publication or preprint, not the current version of any commercial detector. This skill did not revisit the URLs.

Each entry ends with an evidence label (defined in `detection-principles.md`):

| Label | Meaning |
|---|---|
| [V] | Provider or standards documentation: what a vendor, maintainer, or standards body says about its own product or specification |
| [R] | Research finding: a result from a named study under its stated conditions |
| [C] | Community observation or overview (the two Wikipedia pages) |
| [P] | Project documentation or documented design: what the Turnitout-Humanizer project says it does or intends |
| [O] | Verified source observation: public code the source report inspected directly at a pinned commit |

Editing note: semicolons inside the source's annotations were changed to full stops to fit the user's house style. Titles, authors, years, venues, DOIs, and URLs are unchanged.
