# Governing Requirements (user specification, verbatim)

This is the user's own specification for every Response to Reviewers document. It is reproduced word for word; only line breaks were added between requirement groups. Read it in full at the start of every run. Where SKILL.md and this file differ, this file wins.

Placeholders: `@[MANUSCRIPT FILE]`, `@[SUPPLEMENTARY FILE]` and `@"Peer Reviews.md"` stand for whatever manuscript, supplementary and reviewer files the user supplies in the current request.

---

Understand my complete manuscript using the provided manuscript files @[MANUSCRIPT FILE] and @[SUPPLEMENTARY FILE], together with the reviewer comments in @"Peer Reviews.md". I have already addressed and implemented all reviewer comments and requested revisions in the manuscript and supplementary materials. Your task is to carefully compare the reviewer comments against the revised files and prepare a professional, publication-ready Response to Reviewers report in LaTeX (.tex).

**Requirements**

**Do not miss any reviewer comment**
Identify every reviewer, every numbered comment, and every sub-comment. Preserve the original order and structure of the reviewers' comments. Do not combine separate comments unless they are clearly inseparable. Make sure every comment has a corresponding response.

**For each reviewer comment, provide:**
Reviewer Comment: Reproduce the reviewer's comment accurately, without changing its meaning.
Response: Write a concise, respectful, professional, and evidence-based response explaining how the concern was addressed.
Action Taken: Clearly describe what was changed, added, removed, clarified, revised, or corrected.
Location in Manuscript: Specify exactly where the revision can be found, such as: Page number Section/subsection Paragraph Table number Figure number Equation number Appendix Supplementary material Line numbers, when available

**Verify every response against the revised files**
Do not claim that a change was made unless it is actually present in the provided files. Do not invent page numbers, sections, equations, figures, tables, references, or other manuscript details. When a revision appears in multiple locations, mention all relevant locations. Distinguish clearly between changes made in the main manuscript and supplementary materials.

**Maintain an appropriate academic tone**
Use professional, respectful, and diplomatic language throughout. Acknowledge valid reviewer concerns appropriately. Avoid defensive, argumentative, vague, or overly informal wording. Make responses specific and substantive rather than using generic statements such as "We have revised this accordingly." Use American English consistently.

**Structure the report professionally**
Begin with a brief and professional introductory note thanking the reviewers and editor. Organize the report by Reviewer 1, Reviewer 2, Reviewer 3, etc. Clearly distinguish reviewer comments from author responses. Use consistent numbering and formatting throughout. Include a clear visual hierarchy for reviewer comments, responses, actions taken, and manuscript locations.

**Create a polished LaTeX document**
Produce a complete, compilable .tex file. Use a professional academic/report layout suitable for journal resubmission. Use tasteful, consistent colors and typography. Use visually distinct boxes or environments for reviewer comments and author responses where appropriate. Ensure tables, lists, section headings, page numbering, hyperlinks, and cross-references are professionally formatted. Keep the design elegant and restrained rather than decorative. Ensure the document remains readable when printed or converted to PDF.

**Quality control**
Cross-check the reviewer file and manuscript carefully before finalizing. Perform a comment-by-comment completeness check. Ensure there are no unanswered comments. Ensure every response accurately reflects the revision that was actually made. Ensure every cited manuscript location is correct based on the provided files. Flag any reviewer comment that cannot be verified from the available files rather than guessing.

**Final Output**
Generate the final Response to Reviewers LaTeX (.tex) file only after completing the full cross-check. The final document should be publication-ready, internally consistent, professionally written, and sufficiently detailed for direct submission to the journal.
